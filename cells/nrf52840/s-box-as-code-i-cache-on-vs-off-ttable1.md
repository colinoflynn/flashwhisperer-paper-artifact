## Note

There is no T-table arm of this experiment and there is not meant to be one, so this is not a cell the bench owes. The configuration is a two-arm comparison of ONE lookup mechanism -- rigs/fw_nrf_aes/scode.c builds aes_scode_encrypt (a computed call into a stub table) and aes_sdata_encrypt (an LDRB) from one macro body with the same round keys, the same ShiftRows and the same MixColumns, differing only in how SubBytes fetches a byte.
